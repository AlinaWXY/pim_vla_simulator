01 / MODEL

PIM

共享 X 的 QKV projection、QK、PV/SV、FFN gate/up/down。QKV 权重单份，QK 在 BG 内合并四个 bank 的部分和。

GPU

Q/K RoPE、Softmax、O projection、Norm、GELU-product、残差及最终 32 路 FFN partial reduction。AdaRMS conditioning linear 已预缓存。

数据布局

02 / TILING

每 bank 的驻留区域

90 KiB / bank，45 MiB / 层，18 层共 810 MiB PIM 阵列预留；GPU O 权重另有 72 MiB。Q cache 仅 source banks 有有效数据，其余预留为空洞。SRAM buffers 不计入上述阵列容量。

输入双缓冲 1024 B / rank；QKV accumulator 768 B / bank；QK partials 预留 4096 B / bank；BG score 输出双缓冲 2048 B；Q relay staging 为 32 B / channel。DRAM tCK=0.938 ns，MAC 批次服务参数为 16 CK；这些是仿真时序设定，不是独立验证的 MAC 物理频率。
