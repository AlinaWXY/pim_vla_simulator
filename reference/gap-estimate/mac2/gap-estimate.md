## f、g 的 AE solo 重叠估算

端到端时间等于计费 AE 加 c–e 使用的同一份 VLM profile 时长，再减去 VLM 可在 AE 期间完成的时间。两个 AE solo 切片各重复 180 次。f/g 均按旧版共享张量口径去重，同时沿用当前 trace 中的 AE GPU 块时长。

私有 PIM 计算指描述符内走私有 CA 的本地访问与运算，例如 LOCALRD、BCAST、MACAB、本地 RoPE 和结果写回。描述符发令占用共享 CA。AE solo trace 记录的是 stage 和 I/O epoch 边界。估算取含私有计算的 stage 在所有通道均处于 I/O epoch 外的时长，按理想重叠计入。该窗口也可能包含屏障及等待。Q 交换及其余非去重传输全程计入 AE。去重阶段原本就在 I/O epoch 内，扣除后 epoch 外重叠时长相同。

### g 的模型口径对照

逐请求闭环在 AE 时间里计入原生 PIM I/O。g 的重叠估算在 AE 中计入按旧版规则去重后保留的 PIM I/O。VLM 的实测 kernel 时长来自 Thor 自然缓存 trace，包含该次执行实际经历的访存等待。L2 读 miss 和写流量代理来自单独采集的计数器。

逐请求闭环在 I/O epoch 期间限制新 GPU DRAM 命令，已发请求仍可返回。kernel 完成时刻取实测时长下限与 DRAM 请求完成时刻中的较晚者。重叠估算把整段 I/O epoch 作为 VLM 暂停时间，影响的是 AE 结束后的 VLM 剩余量。

### AE GPU 计时与历史共享张量 I/O 去重

早期账本（`09234a9`）用冷缓存的 AE GPU kernel 时长，保留的 GPU producer 或 consumer 如果已承担同一共享张量的存取，便在合成 AE 时间线中去除对应的 native phase。当时的规则包括融合输入暂存写入、QKT score 批量读出及 GPU RoPE 的 Q/K 导入导出，原始 DQ 流量和时间线完整保留。

当前 AE 输入对普通保留 kernel 使用自然缓存 trace，对另测的边界 helper 使用 32 MiB 清缓存后的设备 kernel 中位数。两类时长都包含各自运行时经历的访存。f/g 沿用旧版共享分配假设，将对应的暂存写入及 score 读出归入现有 GPU producer 或 consumer。f 额外去重 GPU RoPE 已覆盖的 Q/K 导出和导入。跨 rank Q 交换和其他结果导出仍计入 AE。

## 口径与局限

- 只计 DQ，忽略 CA 争用和 rank0 行冲突。GPU 仅使用空隙，PIM 时间线固定，相当于理想的 pim_head。
- 每单元均采用 memory-bound 流体速率。PIM 占用时间按 1:1 计入损失。VLM 损失在活跃 PIM stage 内按 T 减 16 通道平均 ΣU 计算，AE GPU 块暂停 VLM，等待时间为零。
- 写不能超前于读。实际 kernel 的读写交替形状未建模。单元在最慢通道完成时结束，其它通道在同一空隙内可以等到该时刻继续下一单元。
- α 只缩放代理写请求，按原生输入约定向上取整到 sector，随后将请求平均分给 16 通道。每个 α 都从 profile 时长重新计算每条请求的 CK。
- same_first 无历史时优先读，best 的入口成本相同时沿用 same_first。random 按剩余读写比例抽样，条件是两个方向当前均可发。表中 random 为固定种子样本均值，JSON 记录种子、样本和 total 的标准误。
- 每个空隙先假设尾方向等于入口方向，最多重新计算两次右边开销。仍不收敛时预留两方向中较大的右边开销，JSON 按阶段记录次数。ΣU 是可用容量，逐空隙表另列实际发射的读写数，起止 CK 相对各自 stage 的起点。
- DQ 估算把独立启动的单层 AE solo 时间线重复 180 次。层外 AE GPU 块和跨层 DRAM 状态延续未进入该模型。g 的代表性对照用两个实跑 AE solo 切片分别重复 180 次。
